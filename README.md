
# News Recommender 📰✨

The News Recommender is a web-based application designed to provide personalized news article recommendations based on user preferences. Users can filter news articles by date 📅 and category 📚 to view the most relevant content, ensuring a tailored news-reading experience. The app offers a variety of categories, including Technology 💻, Health 🏥, Finance 💰, Politics 🏛️, Entertainment 🎬, Science 🔬, and Sports ⚽.

## ✨ Features

- 🔍 **News Filtering** – Filter news by **date** and **category**.
- 📅 **Past 7 Days View** – Displays news from the past week automatically.
- 🖱️ **Interactive UI** – Clean and responsive interface with smooth button effects.
- 🔗 **Read More Links** – Direct access to full news articles via embedded buttons.
- 🌐 **Dynamic Fetching** – News updates fetched using real-time filters.
- 🎨 **Modern Design** – Gradient backgrounds, hover effects, and neat card layouts.
- 📱 **Responsive Layout** – Optimized for both desktop and mobile screens.
- 🏠 **Navigation** – Quick return to homepage with a single click.
